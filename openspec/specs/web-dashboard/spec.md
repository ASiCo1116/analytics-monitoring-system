# web-dashboard Specification

## Purpose
提供瀏覽器操作介面，讓使用者登入後依角色使用即時監控、資料記錄、資料分析與系統管理功能，並看到每秒更新的即時圖表。

## Requirements

### Requirement: 登入、註冊與登出
未登入的使用者 SHALL 只能看到登入／註冊頁。登入成功後進入即時監控頁，側邊欄顯示目前使用者名稱、角色與登出按鈕。登出 MUST 清除該瀏覽器分頁的登入狀態、停止即時資料接收，並清除保存登入的 cookie。註冊成功後提示使用者登入。

#### Scenario: 登入成功
- **WHEN** 使用者在登入頁輸入正確帳號密碼
- **THEN** 進入即時監控頁，側邊欄顯示其名稱與角色

#### Scenario: 登入失敗
- **WHEN** 使用者輸入錯誤密碼
- **THEN** 停留在登入頁並顯示錯誤訊息，不設定 cookie

#### Scenario: 登出
- **WHEN** 使用者點擊登出
- **THEN** 回到登入頁，無法再看到其他頁面

#### Scenario: 登出後重新整理
- **WHEN** 使用者登出後重新整理頁面
- **THEN** 仍是登入頁，不會恢復登入

### Requirement: 依角色的多頁面導覽
介面 SHALL 為多頁面架構，包含：即時監控、資料記錄、資料分析、系統管理。「系統管理」頁 MUST 只對 Admin 顯示；Viewer MUST 看不到新增、編輯、刪除與匯入的操作元件。介面隱藏操作不取代後端權限檢查。

#### Scenario: User 的選單
- **WHEN** User 登入
- **THEN** 側邊欄有即時監控、資料記錄、資料分析，沒有系統管理

#### Scenario: Viewer 的資料記錄頁
- **WHEN** Viewer 開啟資料記錄頁
- **THEN** 可瀏覽與篩選表格，但沒有新增、編輯、刪除、匯入元件

### Requirement: Session 過期處理
當後端回應 401（token 過期或無效）、因帳號停用回應 403，或 WebSocket 以 close code 1008 拒絕連線時，介面 SHALL 視為登入已結束：清除登入狀態與保存登入的 cookie、停止即時資料接收、回到登入頁並提示「登入已過期或帳號已停用，請重新登入」。一般權限不足的 403 不登出，只顯示錯誤訊息。

#### Scenario: Token 過期
- **WHEN** 使用者的 token 過期後在資料記錄頁按下查詢
- **THEN** 回到登入頁並顯示過期提示

#### Scenario: 帳號被停用後重新整理
- **WHEN** Admin 停用某使用者後，該使用者重新整理頁面
- **THEN** 顯示登入頁與過期提示，不會恢復登入

### Requirement: 即時監控頁
即時監控頁 SHALL 每秒自動更新，顯示：各伺服器目前所選指標的數值卡片（異常時以紅色與警示符號標示）、最近 60 秒的折線圖（每台伺服器一條線，異常點以紅色標示，並畫出閾值線）、各伺服器當下數值的柱狀圖（超過閾值的柱子為紅色）、最近 20 筆告警清單，以及連線狀態指示。使用者可切換要看的指標。切換到其他頁面再回來時，已收到的資料 MUST 保留。

#### Scenario: 圖表即時更新
- **WHEN** 使用者停留在即時監控頁 5 秒
- **THEN** 折線圖至少新增 5 個時間點，不需手動重新整理

#### Scenario: 異常顯示
- **WHEN** 收到 server-2 cpu=95（閾值 90）
- **THEN** server-2 的數值卡片、折線圖上的該點與柱狀圖中的柱子都以紅色標示，告警清單新增一筆

#### Scenario: 後端斷線
- **WHEN** WebSocket 連線中斷
- **THEN** 連線狀態顯示「已斷線」，並在數秒內自動重連

### Requirement: 資料記錄頁
資料記錄頁 SHALL 提供分類、日期範圍、數值範圍、關鍵字篩選與排序選項，以分頁表格顯示結果，並依權限提供新增表單、編輯／刪除（僅自己的記錄或 Admin）與 CSV/JSON 匯入（顯示匯入結果或逐列錯誤）。

#### Scenario: 匯入失敗顯示錯誤
- **WHEN** User 上傳含錯誤列的 CSV
- **THEN** 頁面列出每個錯誤的列號與原因，資料未被匯入

### Requirement: 資料分析頁
資料分析頁 SHALL 可切換資料來源（資料記錄／即時監控資料），設定時間範圍與分類或指標／伺服器，顯示統計摘要卡片、分組聚合柱狀圖、趨勢折線圖，並提供 Excel 下載按鈕。

#### Scenario: 切換來源
- **WHEN** 使用者將來源切換為即時監控資料並選擇 cpu
- **THEN** 統計、聚合（依伺服器）與趨勢圖都改為 cpu 指標的結果

### Requirement: 系統管理頁
系統管理頁 SHALL 以分頁標籤提供：使用者管理（表格中可修改角色與啟用狀態後儲存）、系統日誌查詢、資料庫狀態、即時資料歷史查詢。

#### Scenario: 修改角色
- **WHEN** Admin 在使用者表格中把某人改為 Viewer 並儲存
- **THEN** 顯示成功訊息，重新載入後表格顯示新角色

### Requirement: 重新整理後保持登入
登入成功後，介面 SHALL 將登入憑證保存在瀏覽器 cookie，cookie MUST 設為 HttpOnly 與 SameSite=Lax，有效期不超過 token 本身的有效期，經由 HTTPS 存取時 MUST 加上 Secure。token MUST NOT 出現在網址列或瀏覽紀錄中。重新整理頁面或在同一瀏覽器開新分頁時，若 cookie 中的 token 仍有效且帳號仍啟用，介面 SHALL 直接恢復登入狀態，不需重新輸入帳密；若已無效，MUST 清除 cookie 並顯示登入頁。

#### Scenario: 重新整理後仍在登入狀態
- **WHEN** 已登入的使用者在資料記錄頁重新整理瀏覽器頁面
- **THEN** 仍停留在資料記錄頁，側邊欄顯示其名稱與角色，不需重新登入

#### Scenario: 開新分頁
- **WHEN** 已登入的使用者在同一瀏覽器開啟新分頁進入系統
- **THEN** 新分頁直接是登入狀態

#### Scenario: Token 到期後重新整理
- **WHEN** token 到期後使用者重新整理頁面
- **THEN** 顯示登入頁（cookie 與 token 同時到期，瀏覽器不再送出）

#### Scenario: Cookie 中的 token 已失效
- **WHEN** cookie 中的 token 被後端拒絕（例如簽章金鑰已更換），使用者重新整理頁面
- **THEN** 顯示登入頁與過期提示，cookie 被清除

#### Scenario: JavaScript 讀不到 token
- **WHEN** 登入後在瀏覽器開發者工具執行 `document.cookie`
- **THEN** 結果中沒有登入用的 token
