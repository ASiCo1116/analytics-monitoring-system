# Spec Delta

## MODIFIED Requirements

### Requirement: 資料記錄頁
資料記錄頁 SHALL 提供分類、日期範圍、數值範圍、關鍵字篩選與排序選項，以分頁表格顯示結果，並依權限提供新增表單、編輯／刪除（僅自己的記錄或 Admin）、批次刪除與 CSV/JSON 匯入（顯示匯入結果或逐列錯誤）。批次刪除時，Admin 與 User SHALL 能在表格中勾選目前頁面的多筆記錄，確認後一次刪除；選取中沒有權限刪除的記錄 MUST 被略過並提示筆數。Viewer 的表格 MUST 不能勾選，也沒有批次刪除元件。

#### Scenario: 匯入失敗顯示錯誤
- **WHEN** User 上傳含錯誤列的 CSV
- **THEN** 頁面列出每個錯誤的列號與原因，資料未被匯入

#### Scenario: 批次刪除選取的記錄
- **WHEN** User 在表格勾選 3 筆自己的記錄，勾選確認後按下刪除
- **THEN** 3 筆記錄被刪除，表格重新載入並顯示「已刪除 3 筆記錄」

#### Scenario: 選取中包含他人的記錄
- **WHEN** User 在表格勾選 2 筆自己的記錄與 1 筆他人的記錄
- **THEN** 頁面提示有 1 筆不是自己建立、會被略過，確認刪除後只刪除自己的 2 筆

#### Scenario: 尚未確認
- **WHEN** User 勾選了記錄但沒有勾選確認
- **THEN** 刪除按鈕無法按下

#### Scenario: Viewer 無法批次刪除
- **WHEN** Viewer 開啟資料記錄頁
- **THEN** 表格不能勾選，頁面上沒有批次刪除元件
